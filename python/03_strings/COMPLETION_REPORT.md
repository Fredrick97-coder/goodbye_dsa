### Key Algorithms Explained
1. **Palindrome Check** - O(n) two-pointer approach
2. **Anagram Check** - O(n) hash map approach
3. **Longest Substring** - O(n) sliding window
4. **Edit Distance** - O(n*m) dynamic programming

6. **String Similarity** - O(n*m) Levenshtein
