### Week 11-12: Advanced Topics (Topics 15-18)
- Greedy algorithms
- Bit manipulation

## 💡 Study Tips

### Daily Routine (1-2 hours)
1. **Read theory** (20-30 min)
   - Understand concepts
   - Review diagrams
   - Note complexity

2. **Run examples** (15-20 min)
   - See how it works
   - Modify code
   - Experiment

3. **Solve exercises** (30-45 min)
   - Try without looking at examples
   - Use hints if stuck
   - Verify your solution

4. **Optional: Work on project** (15-30 min)
   - Apply multiple concepts
   - Build something real
   - Optimize if possible

### Weekly Review
- Revisit previous topic
- Try harder exercises
- Implement variations
- Teach someone else (best way to learn!)

## ❓ Troubleshooting

### "I can't solve the exercises"
→ Go back and read theory again
→ Study the examples more carefully
→ Start with just writing the code structure
→ Add one line at a time

### "I understand but can't code it"
→ Practice more examples

### "I'm learning too slowly"
→ Normal! DSA takes time
→ Try easier resources first
→ Spend more time on theory
→ Don't rush through topics

→ Review and teach others
→ Solve real problems (LeetCode)
